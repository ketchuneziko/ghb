# HeartOS v1.0 — игра для Марии

**Главный файл — `index.html`.** Он один и полностью самодостаточный:
шрифт, портреты, звук и весь код внутри. Интернет не нужен, внешних
файлов нет — можно просто отправить файл в Telegram, Мария откроет его
в браузере прямо в чате.

**Что внутри:** компьютер включается (BIOS-загрузка HeartOS) → рабочий
стол с программами → окно `ПРОГРЕСС.exe` с картой → **5 сюжетных
эпизодов (ровно 8 сердец)** → церемония из восьми сердец → большое
письмо → два вопроса → финальная сцена.

**Бонус:** 8 старых мини-игр спрятаны на вкладке `БОНУС` в карте.
Они не входят в счёт 8/8 и не открывают финал — просто чтобы можно
было поиграть ещё.

**Архив:** иконка `АРХИВ.exe` — пять дополнительных игр (`HEART ARCHIVE`).
Тоже не входят в счёт 8/8 и не нужны для финала. После всех пяти на
рабочем столе появляется личный файл `MARIA.txt`. Подробности — в разделе
`HEART ARCHIVE` ниже.

## ✏️ Самое важное, что ты захочешь поменять

### 1. Письмо в финале (главный текст)

Файл **`src/parts/16_finale.js`**, объект `FIN` в самом верху:

```js
const FIN = {
  title: 'ПИСЬМО ДЛЯ САМОГО ДОРОГОГО ЧЕЛОВЕКА',
  text: [
    'Если ты читаешь эти строки, значит, все 8 сердец собраны...',
    '',
    'Спасибо тебе за то, что превращаешь самые обычные дни...',
    'Пусть эта маленькая пиксельная игра напомнит тебе о том...'
  ],
  sign: 'TO INFINITY AND BEYOND',
  ask1: 'Ты останешься со мной?',
  ask2: 'Будешь навсегда только моей?',
  yes: 'ДА',
  lastWords: 'Навсегда. Только моя. Я обещаю.'
};
```

| Поле | Что это |
|---|---|
| `text` | **письмо.** Каждая строка массива — строка на бумаге, `''` — пустая строка-отступ. Длинные строки переносятся сами, длинное письмо прокручивается |
| `sign` | подпись под письмом (рисуется отдельной строкой) |
| `ask1` | первый вопрос: «Ты будешь моей девушкой?» |
| `ask2` | второй вопрос: «Будешь навсегда только моей?» |
| `yes` | единственная кнопка под обоими вопросами — `ДА` |
| `lastWords` | последняя фраза финальной сцены |

> Правь **только этот массив** — это источник истины. Больше нигде текст
> письма не дублируется.

### 2. Имена и цвета

Там же, в `src/template.html`, объект `CONFIG`:

```js
const CONFIG = {
  him: 'Танжар',   // ОН
  her: 'Мария',    // ОНА
  ...
};
```

`cHim` / `cHer` — цвета волос, кожи и одежды у пиксельных человечков
(Мария везде ОНА, Танжар — ОН). Пиксельные портреты нарисованы по фото
и вшиты прямо в `index.html`.

### 3. Реплики Танжара

У каждого эпизода в начале файла есть `intro:` (до уровня) и `outro:`
(после победы) — это **только его слова**, как ты просил:

```js
intro: [D('him','Некоторые слова слишком ценны, чтобы говорить их вслух без защиты.')],
outro: [D('him','Ты знаешь ключ к моим самым сокровенным мыслям!')],
```

Формат: `D('him', 'текст')` или `D('her', 'текст')`. Длинные фразы
переносятся сами, больше трёх строк не влезет.

Текст загрузки — массив `BOOT_LINES` в `src/parts/03_boot.js`.
Строки сейчас такие:

```
Инициализация системы любовного назначения v1.0...
Загрузка самых тёплых воспоминаний...
Готово! Нажмите [Пробел], чтобы войти в моё сердце.
```

### 4. Сложность

В начале каждого файла эпизода лежит объект с настройками:

| Файл | Объект | Что можно крутить |
|---|---|---|
| `11_ep1_cipher.js` | `CIP` | сдвиг, шифровка, подсказка |
| `12_ep2_rhythm.js` | `RTH` | `spb` (темп), `beats` (долей), `win` (побед), `misses` (ошибок), `good` / `perfect` (окна) |
| `13_ep3_memory.js` | `MEM` | `t` — время на эпизод |
| `14_ep4_maze.js` | `MAZ` | размеры лабиринта, лимит ходов (`shortest()*2+14`) |
| `15_ep5_code.js` | `COD` | `maxBad` — сколько ошибок компиляции прощаем |

**Если уровень не даётся:** после третьего проигрыша в окне диалога
появляется кнопка **ПРОПУСТИТЬ** — она всё равно выдаёт сердечко,
чтобы подарок не упёрся в сложность.

## 🖥 Рабочий стол

Иконки на рабочем столе:

| Иконка | Что делает |
|---|---|
| `ШИФР.exe` | запуск первого эпизода |
| `АРХИВ.exe` | HEART ARCHIVE — пять дополнительных игр (появляется всегда; при наведении подсказка `ТУТ ЕСТЬ ЕЩЁ КОЕ-ЧТО.`) |
| `MARIA.txt` | личный экран, появляется только после полного архива 5/5 |
| `ПРОГРЕСС.exe` | окно с картой: вкладка **СЮЖЕТ** (5 эпизодов + финал) и **БОНУС** (8 мини-игр) |
| `КОМАНДНАЯ СТРОКА` | терминал (см. ниже) |
| `ПАРАМЕТРЫ` | эффекты, звуки, музыка, «НАЧАТЬ ЗАНОВО» и строка `HEARTOS работает лучше, когда звук включён.` |
| `README.txt` | записка |
| `КОРЗИНА` | шуточное окно: «Сердца удалять нельзя. Я проверял.» |

Внизу — **статусбар**: `Собрано сердец: 0 / 8` и часы.
Когда собраны все 8, статусбар пишет `ФИНАЛ ОТКРЫТ`.
Если долго ничего не делать, сверху иногда появляется реплика системы
(`СИСТЕМА: ОЖИДАНИЕ. ЭТО НЕ ОШИБКА.`) — список в `27_text_desktop.js`.

**Управление:** стрелки / WASD, `Пробел` — выбор и подтверждение,
`R` — начать уровень заново, `Esc` — закрыть окно / выйти,
`M` — музыка, `N` — звуки, `C` — эффекты экрана,
`Tab` — переключить вкладку карты. В командной строке `M` и `N` — обычные буквы. На телефоне всё то же самое
тапается пальцем.

Прогресс сохраняется сам в `localStorage` после каждого сердечка.

## 🎬 Кампания: 5 эпизодов, 8 сердец

| # | Эпизод | Сердец | Что делать |
|---|---|---|---|
| 1 | **ШИФР** | 1 | сдвинь каждый символ на шаг назад и прочти послание |
| 2 | **РИТМ СЕРДЦА** | 1 | лови настоящий такт `Тук... тук... тук-тук!`: 21 доля, 10 попаданий, 6 промахов — но «жми в такт», а не спамь |
| 3 | **ВОСПОМИНАНИЯ И ЛЮДИ** | 2 | останови три момента ленты (Дайвинчик, разговоры по телефону, бессонные ночи) |
| 4 | **ЛАБИРИНТ И ДОЖДЬ** | 2 | дойди до тёплого огонька под пиксельным дождём. Подсказка: «Возьми зонт и не отпускай меня!» |
| 5 | **ИСПРАВЛЕНИЕ КОДА** | 2 | в программе сбой — избыток милоты. Почини три строки: `while (together) { love += Infinity; happiness = true; }` |

### 🔑 Ответы (спойлеры, для проверки)

| Эпизод | Ответ |
|---|---|
| ШИФР | сдвиг 1 назад → `Я ЛЮБЛЮ ТЕБЯ ДО БЕСКОНЕЧНОСТИ И БЕСКОНЕЧНОСТЬ НЕ ПРЕДЕЛ` |
| РИТМ СЕРДЦА | жми на **сильных** долях (первая и шестая в рисунке `x..x.xx`); паузы жать нельзя |
| ВОСПОМИНАНИЯ | три воспоминания, каждое останавливается на 3-й «полоске» |
| ЛАБИРИНТ | от девочки вверху — вправо до последнего столбца, потом вниз к огоньку (лабиринт всегда связный) |
| ИСПРАВЛЕНИЕ КОДА | строка 2 → `Infinity`, строка 3 → `true` |

> В шифре две буквы «П» в зашифрованной строке потерялись — так текст
> был задан изначально, и он оставлен ровно как есть. Правильный сдвиг
> всегда даёт верный ответ.

### Что ещё есть в архиве

* **Фотография в комнате (игра 05).** В свободной восьмой клетке висит рамка.
  Клавиша `8` (или тап) открывает её: в первом круге там он один и пустое место,
  во втором появляется еле заметный силуэт, в третьем — Мария.
  Ничего не объясняется, просто меняется. Код: `d_photoWall`, `d_photoView`
  в `src/parts/25_room.js`.
* **Созвездие (игра 02).** После победы девять розовых звёзд проступают буквой
  `M`, а потом `M ♥ T` — это подарок, а не загадка (`ARC2_SECRET`).
* **Музыка (игра 03).** Повторив мотив, Мария услышит всю мелодию целиком
  (`ARC3_FINALE`), а под ней — `НЕКОТОРЫЕ МЕЛОДИИ НУЖНО СНАЧАЛА УСЛЫШАТЬ,
  ЧТОБЫ ПОТОМ УЖЕ НЕ ЗАБЫТЬ.`

### Где менять тексты архива

* `ARCH_META` (`20_archive.js`) — имя, подзаголовок, иконка и **две реплики
  на вступление** к каждой игре.
* `AR_HINTS.<id>` (в каждом файле игры) — три подсказки. Показываются с
  шапкой `ПОДСКАЗКА 01 / 02 / 03`.
* `outro: [...]` (в каждом файле игры) — реплики после победы. В конец
  каждого outro автоматически добавляются
  `А теперь возвращайся.` и `Я оставил тебе ещё кое-что на рабочем столе.`,
  а последняя реплика подписана `[ ВЕРНУТЬСЯ ]`.
* Экран победы: `ЗАДАЧА ВЫПОЛНЕНА.` → `ЕЩЁ ОДНА ВЕЩЬ НАЙДЕНА.` →
  `PERFECT SOLVE` (без ошибок и подсказок) или `SOLVED` →
  `ЗАПИСЬ СОХРАНЕНА` → `АРХИВ ОБНОВЛЁН.` → кнопка `ВЕРНУТЬСЯ`.
* Экран неудачи (`arlose`): `НЕ ПОЛУЧИЛОСЬ.` и кнопки `ПОПРОБОВАТЬ ЕЩЁ`,
  `ПОДСКАЗКА`, `ВЫЙТИ`; после трёх попыток добавляется `ПРОПУСТИТЬ`.
  Ошибки **не обнуляют** игру.
* Статусы файлов: `НЕ ПРОЙДЕНО` / `ПРОЙДЕНО` / `ИДЕАЛЬНО` (0 ошибок и 0 подсказок).
* Повторное прохождение: карточка пишет `ТЫ УЖЕ ЗНАЕШЬ, ЧЕМ ЭТО ЗАКАНЧИВАЕТСЯ`
  и `ПРЕДЫДУЩИЙ РЕЗУЛЬТАТ: PERFECT|SOLVED`.
* После 5/5 — экран `ARCHIVE COMPLETE` (`АРХИВ ЗАКРЫТ.`, `Спасибо, Мария.`, `♥`)
  и кнопка `НА РАБОЧИЙ СТОЛ`.
* При следующем входе: `Ты уже всё нашла.` → `Но можешь остаться ещё немного.`
  → кнопка `ОСТАТЬСЯ`.
* После полного архива на рабочем столе появляется личный файл `MARIA.txt`
  (`status: special / memory: too many / smile: detected / heart: occupied /
  owner: Мария / access: forever`). Код — `27_text_desktop.js`.

Сохранения архива лежат в том же ключе `printILY3`, но в блоке `a`
(версия 2). Старые сохранения читаются как есть.

## 💖 Финал

Когда собраны все 8 сердец, в карте открывается узел `ФИНАЛ`. Нажатие на него
больше не сразу открывает финал:

1. **экран `ALL HEARTS RESTORED`** — восемь сердец загораются по одному,
2. **`MEMORY ROOM`** — тёмная комната с тремя фотографиями и столом с `ФИНАЛ.exe`
   (его можно нажать сразу или после всех трёх воспоминаний),
3. `ФИНАЛ.exe` запускает сам финал:
   1. восемь сердец подлетают и закручиваются,
   2. сливаются в одно большое сердце, и оно начинает биться,
   3. на экране появляется **письмо** (`FIN.text` + `FIN.sign`),
   4. вопрос **«Ты останешься со мной?»** — две кнопки: `ДА` и `КОНЕЧНО`,
   5. вопрос **«Давай продолжим это вместе?»** — снова `ДА` и `КОНЕЧНО`,
   6. финальная сцена, конфетти и `Навсегда. Только моя. Я обещаю.`,
      плюс реакция на последний выбор:
      `Я почему-то всё равно волновался.` или `Хорошо. Тогда можешь не уходить.`,
   7. кнопка `ПРОЙТИ ЗАНОВО` — сброс прогресса (и комнаты памяти).

Обе кнопки ведут в один и тот же финал — варианта «Нет» в игре нет.

### MEMORY ROOM — что там менять

Файл **`src/parts/29_memroom.js`**, массив `MR_MEM` в самом верху:

```js
{ id:'MEMORY_01', name:'ПЕРВЫЙ СНЕГ', tag:'СНЕГ', cap:'ОКТЯБРЬ, ГДЕ-ТО ТАМ',
  say:'Первый снег. Ты сказала, что он пахнет ничем...' }
```

* `say` — то, что печатается под фото, `cap` — подпись, которая появляется в конце;
* `tag` — короткая подпись под рамочкой на стене (видна только после просмотра);
* рисунки самих фотографий — `d_photo(i, x, y, w, h, t, dim)` там же;
* `MR` (сохранение) — какие воспоминания уже открыты, блок `m` в localStorage.

### Что можно крутить, чтобы игратьлось ещё интереснее

| Хочется | Где |

Готовые «кирпичики» для своих правок: `burst()`, `burstRing()`, `hitSpark()`,

## Часть 34 · Все тексты в новом стиле + ДОСТИЖЕНИЯ

`parts/34_texts_v2.js` — последняя часть сборки. Она ничего не ломает,
а только подменяет тексты и добавляет окно «ДОСТИЖЕНИЯ».

### Что где лежит

| Что | Как найти в файле |
|---|---|
| Аутро сюжетных эпизодов 1–5 | `EP_OUTRO` → `LEVELS[0..4].outro` |
| Аутро 8 бонусных игр | `BONUS_OUTRO` → `LEVELS[5..12].outro` |
| Аутро игр архива 01–05 | `AR_OUTRO` → `ARCH_LEVELS[id].outro` |
| Длинные реплики | `speak(строки, 48)` режет абзац на короткие реплики (макс. 48 символов) — так диалог всегда влезает в 3 строки даже на экране 240 px |
| DEV LOG 01–04 + FINAL | `DEVLOGS['DEV_LOG_01.txt'] …` (словарь, можно дописывать записи) |
| Письмо `README.txt` | `DEVLOGS['README.txt']` — открывается как обычный текстовый файл со скроллом |
| Описание и статусы `прогресс.exe` | `PROGRESS_DESC`, `PROGRESS_STATUS` — рисуются в `mapWindowContent` |
| Вход/выход из меню «Пуск» | `note2(...)` в обёртке `G.screens.desktop.update` |
| Экран паузы | клавиша **P** (или **З**, или тап) на уровне; тексты в обёртке `G.screens.level.draw` |
| Повтор после ошибки | обёртка `loseLevel` дописывает реплику |
| Награда за успех | обёртка `G.screens.reward.draw` — «Смотри, у тебя всё получилось!» |
| Финал до/после | обёртки `G.screens.finale.enter` / `.draw` |
| Настройки вход/после сохранения | обёртки `openSettings` и `G.screens.desktop.drawWindow` |
| Секретная локация | `Win.open` для `kind==='readme'` открывает письмо; подсказка «здесь что-то скрыто…» — при наведении на иконку |

### Плавающая плашка `note2(текст, цвет, секунды, yTop)`

Короткая реплика, которая сама гаснет. Живёт только на том экране, где
появилась (при смене экрана исчезает), не перекрывает диалоги и загрузку.
Через неё сделаны почти все новые реплики.

### Достижения

* Список — `ACH_DEF` (13 штук, id + название + тихая расшифровка).
* Выдача — `ACH.give(id)`: показывает тост `ДОСТИЖЕНИЕ: …` и плашку
  «Ты открыла ещё одну ачивку!».
* Проверка после победы — `ACH.check(levelIdx)`, hooked на `winLevel`.
* Остальные крючки: пасхалка в терминале (`termExec`), горячая рука,
  «подглянуть», третье фото в Memory Room, `arWin`.
* Сохранение — блок `g` в том же ключе `printILY3` (в `localStorage`).
* Окно: `openAchievements()`, пункт «ДОСТИЖЕНИЯ» в меню «Пуск»,
  стрелки/тап — листать, `Esc` — закрыть.

Очков, уровней и гринда нет: это тихие личные отметки о том, что ты
действительно прошла.
